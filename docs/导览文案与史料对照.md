# 明中都导览文案与史料对照

## 使用原则

- 朱元璋气泡只负责指路、观察提示和功能教学，不让历史人物讲述其身后的考古发现。
- 知识卡采用中性第三人称。能由现场说明、政府文旅、文博机构或正式考古材料确认的内容才写成确定事实。
- 对古井年代、井深、服务对象以及西华门门楼完工状态等尚不充分的信息，使用“可能”“现有认识认为”或明确说明暂不判断。
- 路过讲解只指出照片中可见、玩家能够观察的细节，不用想象性复原替代遗址现状。
