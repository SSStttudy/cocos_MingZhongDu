# 问卷后台与数据导出说明

网页版和微信小游戏版使用同一套问卷结构，并将答卷同步到统一后台：

- 后台管理页：`https://nyasd.net/api/mingzhongdu/feedback/admin`
- 数据来源字段：`web` 表示网页版，`wechatgame` 表示微信小游戏版
- 设备离线时先保存在本机；下一次启动或再次提交时自动补传

## 获取后台口令

后台口令只保存在腾讯云服务器，不要发到群聊、截图或提交到 GitHub。在 PowerShell 中执行：

```powershell
ssh root@122.51.4.154 "cat /etc/mingzhongdu-feedback.env"
```

复制 `FEEDBACK_ADMIN_TOKEN=` 后面的内容，粘贴到后台管理页的“后台口令”输入框。

## 经常导出数据

1. 打开后台管理页。
2. 输入后台口令，点击“查看数量”确认当前答卷总数及两端来源数量。
3. 点击“导出 CSV（Excel）”。下载的 UTF-8 CSV 可以直接用 Excel 打开。
4. 需要完整备份时点击“导出 JSON”；JSON 更适合程序处理和长期归档。

建议每次汇报或集中测试后同时保存一份 CSV 和 JSON，并在文件名中加日期，例如：

- `明中都问卷-2026-09-02.csv`
- `明中都问卷-2026-09-02.json`

CSV 更适合筛选、排序、统计和制作图表；JSON 更完整，适合作为原始数据备份。

## 直接下载接口（可选）

如需脚本化导出，可向以下接口发送 Bearer 口令：

- `GET https://nyasd.net/api/mingzhongdu/feedback/export.csv`
- `GET https://nyasd.net/api/mingzhongdu/feedback/export.json`
- `GET https://nyasd.net/api/mingzhongdu/feedback/summary`

不要把口令写进游戏客户端或公开仓库。后台页只在管理员本机浏览器中临时使用口令。
