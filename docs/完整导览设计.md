# 明中都遗址完整导览设计

## 一、导览定位

导览主题定为：**从地面遗迹读懂一座都城**。

路线不只是依次抵达游客中心、西门、石础、古井和午门，而是形成一条认识过程：

1. 在游客中心认识“这是什么地方”。
2. 从沙盘理解城址的整体格局和中轴秩序。
3. 穿过西侧城垣，由城外进入城内。
4. 从石础读出已经消失的宫殿柱网与建筑尺度。
5. 从古井认识宏大宫城之外的供水和日常设施。
6. 由午门门洞登临城台，在高处回看整条路线。

推荐主线时长为 **12～18 分钟**。玩家可以偏离路线和提前探索，导览始终指向最早未完成目标，不强制封路。

## 二、叙事与解说原则

### 1. 两种声音分工

- **朱元璋形象**只负责指路、节奏和情绪，例如“先去看看那组石础”。
- **遗址知识卡**使用中性第三人称陈述史实，避免让历史人物讲述其身后发生的考古发现。

这样可以保留角色亲和力，同时避免第一人称对白造成史实错位。

### 2. 每站只讲一个核心概念

| 站点 | 核心概念 |
| --- | --- |
| 游客中心 | 明中都是一座怎样的都城 |
| 王剑英雕像 | 遗址如何重新被认识 |
| 明中都沙盘 | 中轴与城门、宫殿的层次 |
| 西侧城垣 | 都城的边界与出入 |
| 石础 | 从柱础和磉墩推断建筑布局 |
| 古井 | 都城中的供水与日常设施 |
| 午门 | 宫城入口、门道和城台空间 |
| 午门城台 | 从单体遗迹回到整座都城 |

### 3. 名称校正

游客中心院落照片中雕像基座显示为“王剑英”，官方介绍也使用“王剑英”。导览显示名应由当前的“王英雕像”修正为 **“王剑英雕像”**；稳定区域 ID `obstacle-wang` 不改。

## 三、完整主线

### 第一章：先看懂这座城

#### 01. 开始页与移动教学

- 场景：`Start → Overworld`
- 目标：跟随第一段路标移动到游客中心。
- 朱元璋：`这片城址很大，咱先去游客中心看清全貌，再沿着遗迹一步步往里走。`
- 教学：首次推动摇杆后再显示路线光点；不单独弹出长教程。

#### 02. 进入游客中心

- 大地图目标：`location-1`
- 建议入口：现有最近入口即可。
- 到达后直接进入游客中心，不在大地图入口弹完整地点卡。
- 任务：`先去院落中的王剑英雕像。`

#### 03. 王剑英雕像

- 地点：`visitor-center`
- 分镜：`exterior`
- 现有区域：`obstacle-wang`
- 新导览目标：在障碍区外生成安全观察点；物体上显示交互图案。
- 触发：接近后点击“查看”，不再仅靠距离自动完成。
- 朱元璋：`城址沉默了很久。先认识让它重新进入公众视野的研究者。`
- 知识卡：`王剑英长期开展明中都田野调查与研究，为辨识和理解这座城址提供了重要基础。`
- 下一目标：`进入室内，查看明中都沙盘。`

#### 04. 明中都沙盘

- 分镜：`interior`
- 现有区域：`obstacle-map`
- 触发：接近沙盘后点击“查看”。
- 朱元璋：`先别急着记每座建筑，找出贯穿南北的那条主线。`
- 知识卡：`明中都以南北中轴组织主要城门、桥梁、宫殿和苑囿，重要空间沿轴线层层展开。`
- 卡片操作：提供“我看懂了”按钮；历史复原切换作为可选体验，不作为完成条件。

#### 05. 返回城址

- 目标出口：`main-road → location-1-east-01`
- 任务：`从东侧出口返回大地图，前往西侧城垣。`
- 朱元璋：`全局已经看清。接下来穿过城垣，真正走进这座城。`

### 第二章：穿过都城边界

#### 06. 西门外侧

- 大地图目标：精确入口 `location-4-west-01`，不再由系统任选最近入口。
- 进入：`Location4 / main / spawn-overworld-west-01`
- 任务：`沿门前道路走向城门。`
- 不在入口处立即判定“西门完成”。

#### 07. 穿过西侧城垣

- 新交互区域：`main/interaction-west-gate`
- 建议位置：宽幅照片中门道与城墙主体附近，路线终点落在可行走路面。
- 朱元璋：`城墙划出都城的内外。穿过门道，脚下的空间就变了。`
- 知识卡：`明中都保存有规模宏大的皇城城墙遗存。城墙采用下宽上窄的稳定结构，砖石构筑至今仍能清楚显示城的边界。`
- 完成方式：观察后继续向画面另一侧移动，由 `location-4-east-01` 返回大地图。
- 恢复点：东侧入口外安全道路。

### 第三章：从石头读出宫殿

#### 08. 前往石础

- 大地图目标：精确入口 `location-2-north-01`。
- 进入：`Location2 / 1 / spawn-overworld-north-01`
- 内部路线：`1 → 2`。
- 选用北侧入口是因为分镜 1、2 能直接观察石础；东侧入口通向园路支线，保留为自由探索路径。

#### 09. 石础观察

- 新交互区域：`2/interaction-stone-base`
- 建议位置：分镜 2 前景石础组，不覆盖人物可行走道路。
- 朱元璋：`殿宇不在了，柱子落脚的位置还在。看看这些石础怎样排布。`
- 知识卡：`考古工作可根据磉墩、柱础等遗存判断建筑柱网、尺度和布局。明中都前朝区的建筑遗迹，为研究明初官式建筑提供了实物线索。`
- 小互动：高亮三处石础，玩家依次点击；只要求找到任意两处即可完成，避免手机点选过难。
- 返回：`2 → 1 → location-2-north-01`。
- 恢复点：北侧入口外安全道路。

### 第四章：宏大都城也有日常

#### 10. 前往古井

- 大地图目标：精确入口 `location-2-5-west-01`。
- 进入：`Location2_5 / 1 / spawn-overworld-west-01`
- 内部路线：`1 → 2`。

#### 11. 古井观察

- 现有障碍：`2/obstacle-well`
- 新交互区域：`2/interaction-ancient-well`
- 安全要求：交互区域覆盖井体，导航终点必须位于井外围可行走区，不能引导角色压到井口。
- 朱元璋：`都城不只有大门和宫殿。水从哪里来，也是生活能不能运转的关键。`
- 知识卡首版：`井状遗存提醒我们，考古关注的不只是宏伟建筑，也包括供水、排水和日常使用空间。`
- 史实边界：在取得现场标牌或考古报告前，不写具体开凿年代、井深和服务对象。
- 返回：`2 → 1 → location-2-5-west-01`。

### 第五章：沿午门登临城台

#### 12. 前往午门

- 大地图目标：`location-3-north-01`
- 进入：`Location3 / 1 / spawn-overworld-north-01`
- 内部主路：`1 → 2 → 3 → 4 → 5 → 6 → 7 → 8`。
- 中间分镜仅更新任务与路标，不逐张弹卡，保持游览节奏。

#### 13. 午门门洞

- 新交互区域：`5/interaction-wumen-passage`
- 建议位置：分镜 5 门洞砖券与甬路附近。
- 朱元璋：`先别急着登城，抬头看看门洞怎样托住上方的城台。`
- 知识卡：`午门位于宫城南向重要入口位置。现存门洞、城台和台基装饰，使人仍能辨认它的空间尺度。`
- 完成后路线继续指向分镜 6，不要求原路返回。

#### 14. 午门正面与城台

- 可选中途区域：`6/interaction-wumen-front`，只弹短提示，不计主线进度。
- 短提示：`退后一点，三座门洞与两侧城台的整体关系会更清楚。`
- 主线继续：`6 → 7 → 8`。

#### 15. 登临午门城台

- 新地点区域：`8/location-wumen-platform`
- 这是人物能走到的位置，使用“地面影子＋悬浮地点图案”，不是物体交互图案。
- 朱元璋：`从一块石础、一口井走到这里，你看到的已经不再是孤立的遗迹。`
- 完成卡：
  - 标题：`主线完成 · 从遗迹读懂中都`
  - 正文：`城墙确定边界，石础留下建筑秩序，古井保存日常痕迹，午门把它们重新连回都城中轴。`
  - 按钮一：`留在午门自由探索`
  - 按钮二：`返回大地图`
- “返回大地图”直接回到 `location-3-north-01` 外的安全道路，不要求玩家倒走八个分镜。

## 四、导览状态设计

现有 `visitedStepIds` 不足以表达“进入地点但尚未观察核心遗迹”。完整版本应拆分为：

- `discoveredStepIds`：提前到过或看过，但尚未轮到。
- `completedStepIds`：按主线条件完成。
- `currentStepId`：最早未完成目标。
- `resumeAnchor`：最近安全恢复点。
- `completed`：主线完成。

进度存储升级为 `ming-zhongdu.tour.v2`，读取 v1 时迁移已完成步骤。正式版本将跨会话保存打开；当前 `PERSIST_PROGRESS_BETWEEN_SESSIONS = false` 仅适合测试，完整导览上线前必须启用持久化。

### 安全恢复点

| 阶段 | 恢复点 |
| --- | --- |
| 游客中心雕像 | `exterior/spawn-visitor` |
| 游客中心沙盘 | `interior/spawn-exterior` |
| 西侧城垣 | `main/spawn-overworld-west-01` |
| 石础 | `1/spawn-overworld-north-01` |
| 古井 | `1/spawn-overworld-west-01` |
| 午门 | 当前已抵达分镜的来向出生点 |
| 主线完成 | `location-3-north-01` 外安全道路 |

## 五、地图和地点引导规则

### 大地图

- 导览目标使用**精确入口 ID**，不再只用地点组 ID 后选择最近碰撞点。
- 路线仍按道路节点最短路径生成光点。
- 玩家偏离时重新规划，不自动移动、不封路。
- 抵达入口只负责进入地点，不提前完成该地点的导览任务。

### 小地点

- 以 Transition 图计算当前分镜到目标分镜的最短路径。
- 不在目标分镜时，地点标识显示在正确切景区。
- 到达目标分镜后：
  - 可走到的位置使用地点标识。
  - 文物、雕像、沙盘、井和石础使用交互标识。
- 交互目标先导航到障碍外安全观察点，进入距离后显示“查看”按钮。
- 同一知识卡只完整播放一次；重复访问只显示简短标题。

## 六、UI 层级

1. 左上任务卡：章节、目标、总进度，例如 `5/8`。
2. 右下朱元璋：可拖动；单击显示或隐藏气泡；拖动时隐藏气泡。
3. 场景路标：路线光点、地点标识、交互标识沿用现有视觉。
4. 知识卡：标题、一段 40～80 字正文、“继续”按钮；可选“了解更多”。
5. 完成卡：提供自由探索和返回大地图两个明确出口。

任务卡和知识卡继续使用约 50% 透明的深色背景，避免遮住照片主体。

## 八、实施顺序

### 第一阶段：路线闭环

- 扩充导览步骤类型和 v2 进度。
- 大地图支持精确入口目标。
- 每个地点进入后不立即判定完成。
- 完成西门穿越、石础观察、古井观察和午门登台的完整闭环。

### 第二阶段：交互与知识卡

- 添加六个区域。
- 接入“靠近后点击查看”。
- 完成知识卡和短提示。
- 修正“王剑英雕像”显示名。

### 第三阶段：体验打磨

- 调整每段路标密度、触发距离和安全观察点。
- 启用跨会话进度。
- 测试重新开始、提前访问、重复访问及场景恢复。
- 最后再加入更多历史复原图、收集品和 AR，不阻塞首版完整导览。

## 九、验收标准

- 新游戏能从开始页完整走到午门城台，中途没有需要猜测的出口。
- 西门、石础、古井、午门必须完成地点内目标，不能在大地图碰一下就算完成。
- 石础固定从北侧主线入口进入；其他入口仍可自由探索。
- 古井导航停在井外安全位置。
- 午门八个分镜能连续引导，Scene-7 越过 `PerspectiveKeep` 后缩放稳定。
- 关闭游戏后能够从最近安全点继续。
- 提前访问后续地点不会跳过当前目标，轮到时可识别已经发现的记录。
- 主线完成后不再弹出地点阻断卡，玩家可以自由探索或重新开始。
- 任何目标区域缺失时显示警告并提供“跳过本目标”，不能卡死流程。
