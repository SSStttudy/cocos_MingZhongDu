# 背景音乐：Sunset Plains

用户在四个网络试听候选中选定第三首，并授权接入。作者 Yoiyami，来源页面：
[Sunset Plains](https://opengameart.org/content/sunset-plains)。
来源页标注 [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/) 且无需署名；
仍在设置界面保留曲名、作者，在 `sunset-plains-audio.json` 记录来源、处理过程和哈希。
本次未生成新音乐、购买素材或向第三方上传文件。

## 游戏行为

- 从公共 `SettingsOverlay.initialize` 启动音乐服务，覆盖开始页、大小地图和单独打开地点的预览入口。
- `BackgroundMusic` 只有一个持久根节点；切景继续同一首，不重头播放、不创建叠加播放器。
- 首次触摸、鼠标或按键后播放；加载在后台进行，失败不阻塞进入游戏，后续交互在退避时间后重试。
- 使用原有 `musicEnabled`、`loadSettings` 和 `onSettingsChanged`，音乐开关即时静音并暂停；开启后续播。
- `soundEnabled` 与音乐独立。后台隐藏时暂停并静音，前台恢复时再检查开关，防止迟到的原生播放事件破坏静音。
- 游戏音乐音量为 0.55，播放与恢复时有 0.45 秒淡入。打开普通设置或导览弹窗时音乐继续；系统切后台时暂停。

## 文件与处理

- 游戏文件：`assets/resources/audio/sunset-plains-loop.mp3`。
- 原文件约 63.30 MB / 329.68 秒；压缩版约 3.93 MB / 327.68 秒。
- 转单声道、首尾 2 秒重叠交叉淡化、旋转循环起点，响度目标 −22 LUFS，MP3 96 kbps / 32 kHz。
- 解码后实测 −22.44 LUFS / −6.11 dBTP；数值来自 FFmpeg，详细记录见 JSON。
- 资源沿现有 `resources` 包加载；微信发布脚本将该包移至远程目录。音乐没有放入开始场景的序列化引用。
- 原 WAV 留在 `art-review/audio/sunset-plains-source` 且被忽略，不把 63 MB 母版写入 Git。
- 同目录保存来源页及 CC0 条款快照。原曲未披露制作工具，本项目不补填或猜测。

复现处理使用 `tools/audio/prepare-sunset-plains.py`，需要 NumPy 和临时目录中的 imageio-ffmpeg。
审查页仍保存四个网络候选；原有本地合成曲未接入游戏。
