# 小地点照片透视场景模板

## 1. 设计定位

小地点不是缩小版俯视地图，而是参考《蜡笔小新：煤炭镇的小白》的照片透视探索场景。

| 项目 | 大地图 | 小地点 |
|---|---|---|
| 视角 | 俯瞰 | 固定镜头的照片透视 |
| 移动 | 沿道路图移动 | 在照片地面多边形内正常行走 |
| 空间组织 | 一张大地图 | 多张分镜图片组成场景网络 |
| 进入逻辑 | 道路入口进入地点 | 门口、画面边缘切换下一分镜 |
| 画面 | 俯瞰转绘图 | 实拍照片转绘的现状图与复原图 |

## 2. 当前游客中心分镜

文件夹 1 中已审批的 7 张风格图现已登记为独立照片分镜：

| 分镜 ID | 内容 |
|---|---|
| `entrance-gate` | 入口桥与门区 |
| `main-road` | 中轴道路 |
| `cafe-garden` | 咖啡庭院 |
| `leisure-plaza` | 休闲广场 |
| `visitor-building` | 展馆外院 |
| `exterior` | 王英雕像院落 |
| `interior` | 室内展厅 |

背景资源统一位于 `assets/resources/locations/visitor-center/scenes/`，运行与编辑预览会按照分镜 ID 自动加载。
区域编辑器也会直接扫描这个目录生成分镜下拉框；添加或替换图片后点击面板右上角“刷新”即可重新扫描。
当前 7 张背景同时作为 `LocationBootstrap` 的显式 `SpriteFrame` 引用保存在模板场景中，以保证 Creator 编辑态无需启动运行时资源包也能立即显示。

其中已建立的基础连接为：

```text
大地图
└─ exterior：王英雕像院落
   ├─ 雕像左侧房屋入口 → interior
   └─ 来路/画面下方 → 返回大地图
       
interior：游客中心室内展厅
└─ 右侧门口 → exterior
```

`interior` 对应外景中王英雕像左侧的房屋内部，其余分镜的连接通过区域编辑器继续布置。

## 3. 透视场景结构

```text
Canvas
├─ PerspectiveCalibration（编辑器预览）
│  ├─ BackgroundCurrent
│  ├─ PerspectiveRegions
│  └─ PlayerStart
├─ RegionEditor
│  └─ Scene-分镜ID
│     └─ OcclusionLine-线ID
│        ├─ Point-A
│        └─ Point-B
├─ ForegroundLibrary（静态前景节点库，默认禁用）
│  └─ 前景资源名（UITransform + Sprite）
├─ Camera
└─ LocationBootstrap

运行时：
PerspectiveWorld
├─ BackgroundCurrent
├─ DebugRegions（可关闭）
├─ BehindPlayer
├─ Player
└─ ForegroundOcclusion
```

`BehindPlayer` 与 `ForegroundOcclusion` 是后续切分树木、雕像、沙盘等遮挡素材的挂载层。

## 4. 场景数据

每个照片分镜在 `LocationConfig.ts` 中配置：

- `walkArea`：角色脚底允许进入的地面多边形；
- `obstacles`：雕像、草地、树池、中央沙盘等不可穿过区域；
- `transitions`：门口、画面边缘等切景触发多边形；
- `playerStart`：进入该分镜后的出生点；
- `spawns` / `Spawn` 区域：可命名、可拖动的出生点；
- `farY` / `nearY`：照片纵深范围；
- `farScale` / `nearScale`：角色远处和近处的缩放比例。

角色越靠近画面上方越小，靠近画面下方越大，从而匹配照片透视。

## 5. 当前交互

- WASD / 方向键移动；
- 移动端虚拟摇杆；
- 只能在可行走多边形内活动；
- 无法穿过雕像、树池和室内中央沙盘；
- 外景靠近雕像左侧房屋入口后进入室内；
- 室内靠近右侧门口后返回院落；
- 外景从来路离开后返回大地图对应入口；
- 右上角按钮或键盘 `R` 切换“遗址现状 / 历史复原”；
- 复原图尚未制作时显示“复原图待制作”，不会切换为空白图。

## 6. 编辑方法

场景文件：`assets/scenes/LocationTemplate.scene`

在 Canvas 的 `LocationBootstrap` 中：

- `Preview Scene Id = exterior`：预览院落；
- `Preview Scene Id = interior`：预览室内；
- `Show Debug Regions`：运行时显示或隐藏区域标记；
- `Exterior Current` / `Interior Current`：当前两张实拍或风格化图片；
- `Exterior Restored` / `Interior Restored`：未来对应的历史复原图片。

当前多边形坐标保存在 `LocationConfig.ts`。完成第一轮手感验证后，再为扩展增加可拖动的多边形控制点和坐标回写功能。

## 7. 美术替换原则

现阶段直接使用实拍图验证空间与玩法。风格样张审批完成后，只替换 SpriteFrame，不改变：

- 照片透视结构；
- 可行走区域；
- 雕像、房屋、沙盘等真实位置；
- 外景与内景的连接关系。

若生成图明显改变这些结构，必须重新审批，不能直接进入游戏。

## 8. 区域编辑器与分镜切换

打开 `扩展 -> 明中都工具 -> 照片透视区域编辑器`：

1. 在面板顶部的“正在编辑的分镜”选择背景。游客中心当前有 `exterior`（外景）和 `interior`（内景）。
2. 切换分镜后，编辑器背景和 `RegionEditor/Scene-分镜ID` 下的区域会同步切换。
3. 新建区域后拖动 `Vertex-*` 顶点；可以移动或缩放整个 `Region-*`，导出时会自动换算。
4. 修改属性、增删区域会自动保存。直接拖动顶点后，需要点击“保存并应用”。
5. “保存并应用”同时保存场景并覆盖 `assets/resources/locations/visitor-center/regions.json`。运行时以该 JSON 为准。

运行时不会显示 `RegionEditor`、顶点、轮廓和调试填色。需要临时检查碰撞范围时，才在 `LocationBootstrap` 中开启 `Show Debug Regions`。

新增其他背景分镜时，在 `LocationConfig.ts` 对应地点的 `scenes` 中添加新的分镜 ID、图片和出生点。扩展会自动读取这些 ID 并加入分镜下拉框；每个分镜的区域独立保存在自己的 `Scene-分镜ID` 分组中。

### Spawn 出生点与切景

1. 区域类型选择 `出生点 Spawn`，用一个小多边形标出角色落脚位置，区域中心就是实际出生坐标。
2. 一个分镜可有多个出生点，统一命名为 `spawn-来源`，例如 `spawn-road`、`spawn-cafe`、`spawn-interior`。
3. 切景区域只需在“目标出生点”中选择 `分镜 / 出生点`，不再分别填写目标分镜和坐标。
4. 保存时仍会写入 `targetSceneId` 与 `targetSpawnId`；运行时按 Spawn 中心落位，旧的固定坐标仅作为兼容后备。
5. 返回大地图时继续填写“大地图入口”，不需要选择 Spawn。

区域 ID 使用小写英文和短横线：

- 可行走区：`walk-main`
- 障碍：`obstacle-对象`，如 `obstacle-tree`
- 出生点：`spawn-来源分镜简称`
- 切景区：`to-目标分镜ID`

请在面板的“区域 ID”输入框中重命名。扩展会同步修改 `RegionShape.regionId` 与层级节点的 `Region-*` 名称；直接在层级管理器重命名的旧节点也会在刷新时被重新识别和规范化。

### 前景遮挡线

前景遮挡统一使用独立的两点黄线，不再使用 Occlusion 多边形。当前已经配置：

- 游客中心 `leisure-plaza`：`chair-1`、`chair-2`；
- 石础遗址分镜 `5`：`front-plants`；
- 午门遗址分镜 `3`、`4`、`5`：`gate-right`、`gate-left`、`gate-both-sides`；
- 西门遗址 `main`：`flowerbed`。

每条线都作为静态节点保存在对应场景的 `RegionEditor/Scene-分镜ID/OcclusionLine-线ID` 下。展开该节点后，直接拖动 `Point-A` 和 `Point-B`：

1. 两点的纵向位置和倾斜决定人物脚底的前后分界；
2. 两点之间的横向范围决定该前景在哪一段路线上生效；
3. 人物脚底位于黄线上方时，透明前景显示在人物上层；位于线下方或线段横向范围之外时，透明前景隐藏；
4. 在“前景遮挡线（独立两点）”面板中填写 `resources/locations/地点/scenes` 下的前景 PNG 文件名（不含扩展名），然后点击“保存并应用”。

前景 PNG 必须与背景使用相同画布、位置和透视，只保留会挡住人物的实体像素。线 ID 使用小写英文和短横线，资源文件统一使用 `分镜名-对象名-foreground.png`。每张 PNG 对应的 Sprite、尺寸、锚点和 SpriteFrame 都静态保存在 `Canvas/ForegroundLibrary`，可在编辑器中直接检查；场景节点与 `regions.json` 中的 `occlusionLines` 会同步保存，运行时代码只克隆已搭好的前景节点并按人物位置切换显隐。
